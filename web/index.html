    Keeping the ship busy

      Trade corridors

      Every lane into the five ports. Your route is drawn heavy. Shaded areas are seasonal weather hazards: red where active this month, dashed outline when out of season. Select a port for its limits.

      Live vessel traffic

      Every ship broadcasting its position (AIS) right now, centred on the Bay of Bengal. Click the map to use it, then select a ship for its name, type, speed and destination. Live map by VesselFinder.

      About the model

      An adaptive regression relearns every week from the vessel's own Baltic index (BCI, BPI, BSI or BHSI, with BDI only as a fallback), China PMI, India IIP, China iron-ore imports and world trade volume. Its forecast feeds a leg-by-leg voyage model: distance, vessel speed, wind and sea state, currents, tides, port time and congestion.

      Data sources

      • Baltic indices: daily closes from a public scrape of Baltic Exchange data (github.com/yieldchaser/Shipping). Iron-ore price: IMF via FRED. China PMI: NBS via DBnomics. Refreshed when the server starts and every six hours.
      • India IIP, world trade volume and bunker price: saved series, as no free current feed exists. The Market trends table shows each series' source and latest date.
      • Weather and currents: Open-Meteo forecasts, seasonal norms beyond 16 days.
      • Port limits: approximations from public sources.
      • Maps: OpenStreetMap contributors.

      How to use

      1. Choose the load port, discharge port and vessel class.
      2. Set the deadweight. Red marks show where a full cargo stops fitting.
      3. Read the cheapest window to fix the charter, then the evidence below it.
